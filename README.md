# 🚚 TMS Pro - Transport Management System

Система управления перевозками для транспортной компании.

## 📋 Описание

TMS Pro - это полноценная веб-система для управления заявками на перевозку, планированием транспорта и отслеживанием грузов. Система включает в себя:

- **Удобную форму создания заявок** с автодополнением адресов и отображением на карте
- **Интуитивное планирование** для логистов с Drag & Drop интерфейсом
- **Визуализацию на карте** всех заявок и маршрутов
- **Отчеты и аналитику** по работе компании
- **Backend на Node.js** с базой данных PostgreSQL

## ✨ Основные возможности

### Для менеджеров:
- ✅ Быстрое создание заявок с автодополнением адресов (Nominatim API)
- ✅ Подсказки адресов при вводе с навигацией клавишами
- ✅ Отображение точек на карте
- ✅ Управление статусами заявок
- ✅ Подбор клиентов из базы (автодополнение)
- ✅ Указание приоритета и сроков доставки

### Для логистов:
- ✅ Drag & Drop планирование заявок
- ✅ Назначение транспортных средств перетаскиванием
- ✅ Календарь планирования по неделям
- ✅ Карта с маршрутами и статусами
- ✅ Отображение свободных и занятых машин
- ✅ Перенос заявок между датами

### Общая функциональность:
- ✅ Отчеты по периоду с статистикой
- ✅ Фильтрация заявок по статусам
- ✅ Визуализация маршрутов на карте
- ✅ История изменений заявок
- ✅ Поддержка приоритетов (обычный, высокий, срочный)

## 🚀 Установка и запуск

### 1. Требования

- Node.js 16+
- PostgreSQL 13+
- npm или yarn

### 2. Установка базы данных

```bash
# Создать базу данных
createdb tms_db

# Импортировать схему
psql -d tms_db -f database/schema.sql
```

### 3. Настройка backend

```bash
# Установить зависимости
npm install

# Настроить подключение к БД в server.js
# Измените пароль PostgreSQL:
const pool = new Pool({
  user: 'postgres',
  host: 'localhost',
  database: 'tms_db',
  password: 'ВАШ_ПАРОЛЬ',  # <-- измените
  port: 5432,
});
```

### 4. Запуск

```bash
# Development режим (с автоперезагрузкой)
npm run dev

# Production режим
npm start
```

Сервер запустится на `http://localhost:3001`

### 5. Демо режим (без backend)

Просто откройте `index.html` в браузере. Система будет работать в демо-режиме, сохраняя данные в localStorage.

## 📖 Использование

### Создание заявки (Менеджер)

1. Перейдите в раздел **"Менеджер заявок"**
2. Заполните форму:
   - Выберите или введите название клиента (автодополнение)
   - Введите адрес загрузки (появятся подсказки)
   - Выберите адрес из подсказок
   - Введите адрес доставки
   - Укажите параметры груза
   - Выберите дату и приоритет
3. Нажмите **"Создать заявку"**

### Планирование (Логист)

1. Перейдите в раздел **"Планирование"**
2. В левой панели увидите новые заявки и доступный транспорт
3. Перетащите заявку на нужное транспортное средство
4. В календаре можно перетаскивать заявки между датами
5. На карте отображаются все маршруты

### Карта заявок

1. Перейдите в раздел **"Карта заявок"**
2. Используйте фильтр по статусам
3. Кликните на маркер для просмотра деталей
4. Используйте кнопки для управления заявками

### Отчеты

1. Выберите период в фильтре
2. Нажмите **"Сгенерировать"**
3. Просмотрите статистику и детали

## 🔄 API Endpoints

### Заявки
- `GET /api/orders` - получить все заявки
- `GET /api/orders/:id` - получить заявку
- `POST /api/orders` - создать заявку
- `PUT /api/orders/:id` - обновить заявку
- `DELETE /api/orders/:id` - удалить заявку

### Клиенты
- `GET /api/clients` - получить всех клиентов
- `GET /api/clients/search?q=query` - поиск клиентов
- `POST /api/clients` - создать клиента

### Транспорт
- `GET /api/vehicles` - получить все ТС
- `GET /api/vehicles/available` - получить доступные ТС
- `PUT /api/vehicles/:id` - обновить ТС

### Отчеты
- `GET /api/reports?start=&end=` - отчет за период
- `GET /api/reports/daily` - дневная статистика
- `GET /api/reports/vehicle-utilization` - загрузка транспорта

## 📦 TMS Freight Calculator - Калькулятор тарифов

### ✨ Возможности

- **Тарифы городов** - редактирование с дефолтными тарифами
- **Агенты** - назначение на каждую милю (забор, магистраль, доставка)
- **Удалённые города** - через агентов с отдельными тарифами
- **Расчёт стоимости** - автоматический расчёт с учётом веса и объёма

### 🗄️ База данных

Новые таблицы для калькулятора:

```sql
-- Города с тарифами
tms_cities (city_name, region, terminal, mile1_*, mile2_*, mile3_*)

-- Агенты с тарифами
tms_agents (agent_id, name, region, cities, tariffs, remote_cities)

-- Связи городов и агентов
tms_cities_agents (city_name, agent_id, mile_position)
```

### 🔧 API Endpoints

```
GET  /api/db/cities          - Получить все города
POST /api/db/cities          - Сохранить город
PUT  /api/db/cities/:name    - Обновить город
DEL  /api/db/cities/:name    - Удалить город

GET  /api/db/agents          - Получить всех агентов
POST /api/db/agents          - Сохранить агента
PUT  /api/db/agents/:id      - Обновить агента
DEL  /api/db/agents/:id      - Удалить агента

GET  /api/db/cities-agents   - Получить связи
POST /api/db/cities-agents   - Сохранить связь
DEL  /api/db/cities-agents   - Удалить связь

POST /api/db/init            - Инициализировать БД
```

### ⚙️ Конфигурация PostgreSQL

Измените в `server.js`:

```javascript
const pool = new Pool({
  user: process.env.PGUSER || 'postgres',
  host: process.env.PGHOST || 'localhost',
  database: process.env.PGDATABASE || 'tms_db',
  password: process.env.PGPASSWORD || 'your_password',
  port: process.env.PGPORT || 5432,
});
```

Или используйте переменные окружения:

```env
PGUSER=postgres
PGHOST=localhost
PGDATABASE=tms_db
PGPASSWORD=your_password
PGPORT=5432
```
